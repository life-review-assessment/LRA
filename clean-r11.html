WHAT LRA DOES

そんなとき、必要なのは

もっと頑張ることではなく、

今の生活を一度、構造として整理すること。

LRAは、困りごとや負担だけを見るサービスではありません。
支えになっていること、守りたいもの、すでに機能している部分、使える資源まで含めて生活全体を整理します。

何を変えるか。何を残すか。次に何を選ぶか。

LRAは、その判断をしやすくするための意思決定支援です。
01

今の状態を確認する

行動、決め方、生活環境、気持ち、休息・回復について、負担と今うまくいっている部分の両方をここ2週間ほどの生活から確認します。

02

回答に合わせて詳しく見る

回答内容に合わせた追加質問で、必要な部分をもう少し詳しく確認します。

03

つながりを整理する

負担が続く流れだけでなく、例外、支え、守りたいもの、使える資源も含めて全体のつながりを整理します。

04

次の一歩を考える

何を変えるかだけでなく、何を変えないかも含めて、次の判断に使える選択肢を整理します。

CLEAN R11 / no app JS / no external CSS / no PWA registration
